# AI Usage Disclosure

This build was developed with AI assistance under human direction.

## Assistance used

- **ChatGPT** supported project planning, documentation drafting and review feedback. A concept image was discussed during planning but is **not bundled** with the game.
- **OpenCode** was the coding agent used for repository inspection, implementation, test/build execution and browser verification.
- Human direction set the scope, fictional setting, rules, economy, acceptance criteria and submission decisions.

The exact tool/model list for the final submission should be confirmed by the team against the event's current disclosure requirements.

## Shipped assets

No image-generation model output, generated video, third-party photographic planet texture, font or audio file is bundled. All shipped visuals are original procedural Canvas 2D textures, CSS/SVG, vector geometry and a small Three.js scene generated at runtime. See the project `README.md` for scope and limitations.

## Data and claims

All supplied scientific values were checked against the cited public pages; physical constants, fictional launch/propulsion/cargo values, game economy and model simplifications are kept separate in the project files and data. This project is not a validated real launch, guidance or landing system.

No NASA logos, agency branding or endorsement are used. The game and the team's submission materials remain responsible for any competition-specific AI declarations.
